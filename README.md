# Imed Kablavi

Digital Forensics Engineering student working on cybersecurity, Linux, digital forensics, OSINT, automation, and desktop software.

I use this account for open-source projects, security tooling, forensic research, and experiments that I can document and test publicly.

## Current work

### [OSINT Roadmap](https://github.com/imedkablavi/OSINT-Roadmap)
A multilingual OSINT learning and investigation framework with structured paths, practical resources, verification guidance, and contributor-maintained tooling.

### [Vidrensic](https://github.com/imedkablavi/vidrensic)
A forensic-oriented DVR/NVR analysis project for storage profiling, evidence reconstruction, video recovery, provenance, and validation.

### [DevDoctor](https://github.com/imedkablavi/DevDoctor)
A Linux workstation diagnostic and repair CLI focused on package-manager awareness, safer repair planning, and developer environment reliability.

### [Web Vulnerability Scanner](https://github.com/imedkablavi/web-vuln-scanner)
An authorized-target web security scanner with scoped crawling, evidence-oriented findings, API discovery, and controlled active checks.

### [Ghosty Input](https://github.com/imedkablavi/ghosty_input)
A computer-vision desktop input project using hand gestures for pointer control and an optional calibrated desk-surface keyboard.

### [Discord Rich Presence](https://github.com/imedkablavi/discord-rich-presence)
A local desktop Discord Rich Presence application for Windows and Linux with privacy controls, activity detection, packaging, and signed update support.

### [OxShift](https://github.com/imedkablavi/oxshift)
A local-first desktop voice studio with real-time audio processing, soundboard support, recording, profiles, diagnostics, and experimental local voice-model integration.

### [Social Media Deletion Guide](https://github.com/imedkablavi/Social-Media-Deletion-Guide)
A multilingual privacy directory for account deletion, data export, activity deletion, and provider-owned privacy resources.
